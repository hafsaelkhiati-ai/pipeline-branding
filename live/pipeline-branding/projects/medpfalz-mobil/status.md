## Stage 1 — Name

**Run:** 2026-09-23. **Status:** complete, 4 candidates handed to Stages 2 + 3.

**Descriptor rule:** every name gets "Krankenfahrten" (or "Krankenfahrdienst") as its descriptor, never "Krankentransport". In Germany, *Krankentransport* is the regulated, medically staffed transport (KTW, needs a licence under the state rescue-services law). A seated transport service using that word risks misleading patients and inviting regulatory problems.

**Glance-level trademark notes below come from general knowledge only. No register or web search has been run yet. That is Stage 3's job.**

Short, easy to say, works as a domain and a logo word. | "lauter" can also be read as "louder" (a minor issue). Might clash with other "Lauter-" businesses in the Kaiserslautern area. |

## Stage 3 — Trademark Clearance

**Run:** 2026-09-23. **Method:** TMview API (DE national, EU/EUIPO, WIPO international marks, all statuses), North Data company register search, web search for real-world use in the region. Relevant Nice classes: **39** (transport) and **44** (medical/care services).

**This is a screening, not a legal clearance opinion.** Before print or a trademark filing, a lawyer check or a formal DPMA application is the final safeguard.

| Candidate | Status | Findings |
|---|---|---|
| LauterMobil | **Clear** | 0 trademark hits (DE/EU/WO). No company in North Data. No business using it on the web. Nearest: "Emil E-Mobility in Lautern" (SWK Stadtwerke KL, class 39, e-car sharing), which is a different name and product, so no conflict. "Lauterbach mobil" is a car dealer in Hessen, unrelated. Bonus: locals call Kaiserslautern "Lautern", so it reads as local mobility. |
| Pfälzer Geleit | **Clear** (trademark). Perception flag remains. | 0 trademark hits. No company. Only related mark: "Seligenstädter Geleit" (expired, historic heritage association in Hessen). Not a legal risk, but *letztes Geleit* is standard funeral language, so it needs a native-speaker gut check for an elderly and sick audience. |
| Weggefährte | **Caution** | No mark in class 39/44. Existing marks are in other classes: "W Weggefährte" (18, leather goods), "WEGGEFÄHRTEN" (32/33, drinks), plus 9/16/41 marks. North Data shows 14+ organisations using it (Remscheid, Deggendorf, Hannover, Munich…), mostly social and support associations. Crowded name, weak distinctiveness, main domains taken. |
| Lautertal Krankenfahrten | **Caution** | No transport or care mark. "Lautertal" marks exist in unrelated classes (ice cream, building supplies, wellness days). Market clash: "Krankentransporte Lautertal" directory listings and the DRK Ortsverein Lautertal Fahrdienst both belong to Lautertal (Odenwald, Hessen): same service, different Lautertal. A place name plus a generic service is likely unregistrable as a word mark, so a copycat couldn't be stopped. |

**Local competitors seen (for positioning, not conflicts):** ViamedGO (registered mark, classes 35/39/45; explicitly serves Katzweiler, Otterbach and Otterberg), DRK Kreisverband Kaiserslautern, Fahrdiensthelden (Lauterecken). None of the 4 candidates resembles them.

**Creative brief:**
- **Must communicate:** safety, reliability, humanity, local roots. Seated transport, not an emergency service.
- **Audience:** elderly and sick passengers, relatives, clinics. So high contrast, heavy rounded type, and nothing thin or small in the core mark.
- **Avoid:** red cross (the emblem is protected in Germany; DRK-Gesetz), star of life, ambulance and siren imagery. They signal Rettungsdienst/Krankentransport, which this business is not.
