# Sub-Blueprint: 07 — Visual Consistency

*Part of [pipeline-brand-strategy.md](../pipeline-brand-strategy.md). Read the global orchestrator first.*

**Status:** Draft v0.1 — unvalidated until the MedPfalz Mobil run confirms it.

## Goal

Confirm the logo, business card, and flyer form one consistent visual identity before the package goes to the client.

## Inputs

- Approved logo (Stage 4)
- Business card file (Stage 5)
- Flyer file (Stage 6)

## Steps — Manual Checklist

Run this by eye across all three deliverables:

1. **Colors** — same brand color palette used consistently (not close-but-different shades) across logo, card, and flyer.
2. **Fonts** — same typeface(s) used for headings and body text across all three; no unintended font substitutions from Canva templates.
3. **Logo treatment** — logo appears at consistent proportions/clear space, same version (not an old export) used everywhere, no stretching/distortion.
4. **Tone/spacing** — layout density and spacing feel like one system, not three separately-designed pieces.

If any item fails, fix it before sign-off — don't ship an inconsistency and note it as "known issue."

## Decision Point

Hafsa signs off on the final package. This is the last gate before client delivery — per `.claude/rules/permissions.md`, client-facing sends still require a separate confirmation with the draft shown.

## Output

Sign-off recorded in the project status file, plus the final asset package (logo + card + flyer) ready for delivery.
