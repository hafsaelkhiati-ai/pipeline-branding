# Sub-Blueprint: 01 — Name

*Part of [pipeline-brand-strategy.md](../pipeline-brand-strategy.md). Read the global orchestrator first.*

**Status:** Draft v0.1 — unvalidated until the MedPfalz Mobil run confirms it.

## Goal

Generate and shortlist 2–4 real name candidates for the brand — not clear a name the client already picked, unless they explicitly gave one.

## Inputs

From the project's intake checklist (see global blueprint):
- Industry, Target Audience, Brand Values, Tagline (if any), Services, Location, Language Target

## Steps

1. Read the brief. If Tagline, Brand Values, or Industry are missing, stop and ask — don't guess what the brand stands for.
2. Generate a working list of name directions based on: what the business does, who it serves, the values it wants to project, and the Language Target (e.g. German-first names must read naturally to a native German speaker, not be an English name with a German gloss).
3. Filter out anything that's an obvious trademark red flag at a glance (identical to a known competitor/brand) before spending time on it.
4. Narrow to 2–4 strongest candidates.
5. Log all candidates (including rejected ones and why) in the project's status file — this is useful history even for names that don't survive Domain/Trademark checks.

## Decision Point

None yet — Stage 1 doesn't approve a name, it produces candidates. The actual selection happens at the **Name Selection Gate** in the global blueprint, after Domain (02) and Trademark Clearance (03) have checked all candidates.

## Output

2–4 name candidates, each logged in the project status file, handed to Stage 2 and Stage 3.

## Equipment

None yet — this is a judgment/generation task, not a scripted one.
